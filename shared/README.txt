[ 홈 디렉토리 ]

  웹 파일, 소스코드 등 모든 작업은 이 경로에서 진행하세요.

[ Flask 웹 서버 실행 예시 ]
  $ cd ~
  $ runapp                # 권장: 로그를 홈 외부 경로에 저장
  $ python3 app.py        # 일반 실행
  브라우저에서 http://학번.robotandi.deamon.io 로 접속

[ MySQL 접속 ]
  $ mysql                 # alias 설정 완료 (학번 계정으로 자동 접속)
  기본 비밀번호는 최초 안내된 개인 비밀번호를 사용하세요.
  본인 학번과 동일한 이름의 데이터베이스가 미리 생성되어 있습니다.

[ 공유 폴더 ]
  ~/shared  폴더에 강사가 제공하는 실습 자료가 업로드됩니다.
  읽기 전용입니다. 수정이 필요하면 홈 디렉토리에 복사 후 사용하세요.
  $ cp ~/shared/파일명 ~/파일명

  - 중요한 코드는 반드시 로컬 PC에 백업해두세요.
    (컨테이너 재생성 시 홈 디렉토리 마운트 파일만 보존됩니다)
